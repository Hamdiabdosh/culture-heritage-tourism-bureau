# Final Notes

The purpose of this questionnaire is to collect **real organizational information first**.

The website structure should then be generated from that information.

Do not create information simply because a field exists in the questionnaire. If something does not apply to the organization, mark it **N/A**.

The organization should approve official names, titles, responsibilities, contact information, public documents, images, and translations before publication.
